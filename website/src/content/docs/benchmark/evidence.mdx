# Evidence Graph

One coding engine builds the same application twice from the same frozen requirements: once with [`@ttsc/evidence`](/docs/evidence) in the workspace, once with neither. Same template, same instruction sequence, same model and effort. The variable is the graph.

Four subjects in ascending size. Every figure comes from `benchmarks/evidence/aggregate` and from nowhere else.

## Coverage

<TtscWebsiteBenchmarkEvidenceCoverage />

Thirteen edges, folded from the leaves up. Serial hops multiply, branches average, and every edge enters once. `C(a→b)` is the share of `a` that reaches `b`; `Q(x)` is how whole an `x` is below itself.

```
Q(test) = Q(journey) = Q(property) = 1

Q(DTO)       = C(column→property)
Q(screen)    = C(screen→journey)
Q(hook)      = C(hook→screen)      × Q(screen)
Q(operation) = mean( C(accessor→test) × Q(test),      C(accessor→hook) × Q(hook) )
Q(model)     = mean( C(model→operation) × Q(operation), C(model→DTO)   × Q(DTO)  )

score = mean(
  C(requirement→model)     × Q(model),
  C(requirement→operation) × Q(operation),
  C(requirement→DTO)       × Q(DTO),
  C(requirement→test),
  C(requirement→screen)    × Q(screen),
  C(requirement→journey),
)
```

Averaging the thirteen rates instead scored one subject 58.4% while 76 of its 557 published accessors had an asserting test. Multiplying them scored the same subject 0.003%. [#1088](https://github.com/samchon/ttsc/issues/1088) derives the operators.

## Reproduce

Clone the repository and tell Claude Code to run the benchmark following the benchmark skill. That skill is the procedure this cohort was produced under, and it owns setup, launch, supervision, recovery, and publication.

```bash
git clone https://github.com/samchon/ttsc.git
cd ttsc
corepack enable
pnpm install
claude "run the evidence benchmark following .agents/skills/benchmark/evidence"
```

The commands it drives, if you would rather drive them yourself:

```bash
pnpm --filter @ttsc/benchmark-evidence start codex <subject> <evidence|plain> <model> <effort>
pnpm --filter @ttsc/benchmark-evidence audit-suspensions
pnpm --filter @ttsc/benchmark-evidence report
pnpm --filter @ttsc/benchmark-evidence charts
```

`<subject>` is a directory under `benchmarks/evidence/requirements`. The runner refuses to launch while anything is uncommitted and records the repository `HEAD` as the run's benchmark revision. `charts` redraws every chart from the published aggregate alone, with no run records present.

`benchmarks/evidence/README.md` documents the runner, the arms, and what a run retains.
