# Validation

`validation-plan.cjs` selects logical suites from the complete Git diff, then groups compatible suites into physical runners. Unknown executable inputs select the full plan. The stable `ci` check requires every selected runner to pass.

The full plan has 16 jobs: seven Linux groups, six shipped-architecture rehearsals, one packed unplugin host rehearsal, and the planner and aggregate. Previously it had 43. Windows/macOS contract groups join their representative artifact runners when selected, otherwise they run independently. Compatible suites share one dependency install and one dependency-safe build union; compiler and lint directory selections also share one executor process. Every independent command runs even after an earlier command fails.

Linux runs the complete scenario inventory. Windows and macOS retain the Go suites and real compiler, path, process, source-plugin, LSP, runtime and watch contracts. The adapter suites still exercise their real OS watch backends. Portable package semantics and evidence benchmark template installations run on Linux once. The minimum supported Node release and the current Node release remain separate runners. Architecture rehearsals verify installed native artifacts on all six supported runner architectures.

`pnpm test:go` prepares all classified `tests/test-lint/src/cases` fixtures and runs them inside one Go process. AST-only rules run directly through the parser and engine; type-aware rules and companion projects load a real compiler program. The corpus keeps its expectation comments, options, filenames, companions and actual checker. The runner rejects empty or unclassified input; each subtest compares every finding's file, rule, severity and line. Audited skip fixtures retain their existing Go harnesses. CLI, config, contributor loading, fix and formatting scenarios remain integration tests.

CI persists the pnpm store, Go modules, Go intermediate objects and content-addressed plugin cache with OS, architecture and Go-version boundaries. Each successful job saves its additions under a new key. Native platform executables are built from the current source. Tests that assert a cold plugin build or cache lifecycle still own their plugin directories; sharing Go objects does not turn a cold plugin entry into a hit. Tests asserting default-cache placement explicitly clear environment overrides.

Run the planner and grouping checks with `node --test scripts/ci/validation*.test.cjs scripts/ci/build-scope-union.test.cjs`. For a local shared build, set `TTSC_BUILD_SCOPE` to a comma-separated list of existing scopes, then run `pnpm build:current`. Run selected suites with `node scripts/ci/run-validation-group.cjs --lanes=ttsc-core,ttsc-native`. Debug the batched corpus alone with `node scripts/test-go-lint.cjs -run=TestLintFixtureCorpus -v`; without arguments the runner executes the complete engine/config suite.
